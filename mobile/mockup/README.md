# Maquette

`sloop-touch.html` est la maquette jouable de l'interface : ouvre-la dans un navigateur (sur téléphone ou tablette
pour tester les gestes). Les sons y sont synthétisés par le navigateur, ce ne sont pas les moteurs de SLOOP.

Elle sert de terrain d'essai : on y teste une idée d'interface (geste, disposition, style), puis on la reporte
dans l'appli C++ (`mobile/app/Source/`). Trois styles sont disponibles (Studio, Pastel, Riso) ; l'appli suit
le style Studio.
